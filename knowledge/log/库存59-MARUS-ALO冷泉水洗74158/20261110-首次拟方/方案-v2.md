# MARUS ALO 冷泉水洗 74158 · v2 机冲配方草案

2026-11-10。用户澄清要 **215ml 过粉＋10ml bypass**，并要求把 bypass 写进 xBloom 配方。目标是试一杯更有花果香和甜感的版本，同时缩短末段过粉。前三段相对 v1 各升 1℃，收尾按用户指定 90℃、3.0ml/s、中心注水。[v2 JSON 草案](方案-v2-bypass.json)用一一旧版的独立 bypass 字段保存精确设定。桥接器已加入这两个字段的解析与编码；本杯仍被独立的215ml比例校验阻止装载，尚未实冲。[首杯记录](记录.md)

## 可执行性核对

一一的[旧配方案例](../../../recipes/yiyi-aged-bean-bypass.json)把 bypass 水量与水温作为独立字段保存，过粉总量仍是各段之和。2026-11-10 用户确认一一扩展可用后，[testCoffee 桥接器](../../../../scripts/xbloom_bridge/protocol.py)按同一编码路径接入了这两个字段，保留严格校验和现有装载、启动流程。15g／215ml 的 1:14.333… 仍过不了当前精确编码校验。离线复算旧版编码器会把分段自动改为 45／61／60／50ml，合计 216ml，本项目未合入这种改水量行为。精确执行215ml过粉＋10ml旁通仍待核对官方App编码或装载证据，不能把本地规则直接断言为机器的全部能力。此配方JSON保持原样。

## 本次观察

前三段合计 165ml，末段用 50ml。前三段升温和磨细用于尝试增强风味，末段用较低温度和较慢的中心注水，绕流用于调整杯感。相较 v1 有多项改动，适合比较整套方案的偏好。对照时关注中温涩与微苦、凉后花果香和甜感，以及排水是否明显变慢。
