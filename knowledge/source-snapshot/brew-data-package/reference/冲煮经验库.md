## 0. 总目标：**风味清晰，结构完整，酸甜平衡，圆润干净**（根本目标 · 用户 2026-11-06 定）

**一切冲煮决策最终服务于这十六个字。** 杜嘉宁（2019 WBrC 世界冲煮冠军）在 Coffeeplus 播客 118 期描述的她喜欢的咖啡，是这四条的具体展开（完整归纳见 `[source-path]/杜嘉宁咖啡偏好归纳.md`）：

- **风味清晰**：干净度与清晰度是底线——"风味复杂的养好的豆子用快流速滤纸，干净度很好，风味清晰度随之会很清晰"。优雅路线——花香、茶调、杏桃调，不炸裂，但风味容易感知（"你去找它，但非常容易找到"）。
- **结构完整**：**有入口**（入口能感受到有东西）→ **滑动过程有身体** → **吞咽以后有尾巴**（余韵）。形态不限——可以粘稠饱满，也可以清爽轻盈，但三段必须都在。**明确反感只有前段的咖啡**（花果香炸裂一下就没了、后段空甚至出谷物/玉米须味）。
- **酸甜平衡**：香气与味道要 match（成熟水果感）——不只是香气像，味道上也要能匹配：柑橘的香气配真的像在吃柑橘的酸质，酸甜有互动。弱酸弱甜、香气单薄的单维表达不够。
- **圆润干净**：触感是重要维度（juicy / 果汁感、滑顺度、稠感），但不是砸脸上的强度——圆润的触感 + 干净的余韵，没有渣感杂味。萃取习惯佐证：往充分萃取方向走——先把豆子的特点全部表现出来，再收着调节"让它更漂亮"。

**对本库的意义**：莎朵这类"清新淡雅、花香清晰但 body 薄"的豆子，方向不是接受轻盈，而是把中段和尾段补出来做到完整——这正好解释了"求萃取更多、风味更强"的既定路线；同时忌讳萃过头让尾段出杂——完整 ≠ 全萃，尾段要"尾巴"不要"渣"。

## 1. 第二层：双指标账（浓度 × 萃取率 · 实现 §0 的量化工具）

**用户 2026-11-06 定：为实现总目标，引入两个指标，所有方案与反馈围绕这两本账。前提是均匀萃取。**

- **浓度（TDS，粉水比口径）**：适宜范围 **1:14 – 1:17，甚至 1:18 都可接受**（日常常用 1:16 基准）。管口腔强度：薄/厚/冲击力。
- **萃取率（EY）**：目标 **18–22%**。管粉里的东西拿出来多少：空/杂/层次/干净度。
- **均匀萃取是前提**：两个指标只有在均匀萃取下才有意义（部分粉过萃+部分粉没动的"平均数"不成立）。破坏均匀的两大失效路径：①部分粉过萃/没动（研磨-水位失衡）；②**旁漏水**——滤纸被细粉堵塞后水改走粉间隙直接流出、未经萃取（见 §4.5 第 5 条，段数过多是诱因之一）。
- **记账规则**：定方案时每个参数改动说清动的是哪本账，说不清的不许进方案；收反馈时先把用户的词翻译成 C/E 判断再选动作（详见 §4.6）。

### 1.1 用户口味画像（执行层面的口味约束）

- **求风味强度与层次**：清新淡雅型豆也要萃取拉满——body 薄若属豆性不算缺陷，但方向是加萃取，不是"保留轻盈"就算满意。
- **结构判据**：凉了（40–50 ℃）更好喝 = 结构成立，不要用过萃填厚度；凉了发空发涩 = 真萃取问题。
- **负面反馈硬规则**：用户给出负面评价（薄/淡/酸/苦/涩/空/闷）时，**先追问中低温三段表现，再下诊断开调整**。用户常只评高温，高低温结论经常相反。
- **浓度路线**：加粉量、保 1:16（16 g 已实测"强度确实更高"）。**默认粉量 15 g**，用户特别说明才改。
- **1:16 是瑰夏底线不可动**：治尾段只动研磨或末段水温，不减末段水量。
- **AG 体系**：数值越大越浅。85–95 = 浅度，>95 = 极浅，<85 = 浅中。
- **禁忌表述**：不得写"水洗比日晒更好萃取"（方向反）。正确因果：水洗密度高→同 AG 更难萃→研磨往细走。

## 3. 判读硬规则

- **杂 ≠ 涩**：涩=单宁收敛感（中温最明显）；杂=余韵浑浊拖沓（细粉+尾段过萃）。治杂靠粗磨，治涩靠粗磨+降收尾温。
- **屏显时间：重要参数，但不作单独判据（用户 2026-11-06 修正）**：屏显 = 总萃取时间，本身是重要指标。**时间过长是果，堵塞/流速慢是因**——单看时间长无法定位因果，必须与逐段液重流速形态联读：时间长 + 流速平滑 = 程序长/正常；时间长 + 流速走低 = 尾段堵。判阻力最终看味觉终点（苦/涩/杂/薄），屏显和流速曲线共同提供"因"的证据。记录"这杯多久"用屏显原数。
- **水位偏高 → 延长中段驻留（用户 2026-11-06 定，观察莎朵 AG95 杯）**：冲煮时滤杯内水位明显高于正常（注水速度跑赢排空速度），说明豆子阻力大、粉床来不及排空。处理：**中段驻留 8→12 s**，让每段注水前粉床先排空，避免水叠床淹 + WAIT 风险；豆子越细（往细调研磨后）越要检查这条。驻留不是"很少动"的参数，**是水位管理的主动旋钮**——阻力大的豆（高密度水洗、极浅、细研磨）中段驻留应该跟上排空需求。
- **驻留决策必须带流速验证（用户 2026-11-06 定，与上条配对）**：延长驻留 = 给细粉迁移更多时间，缩短驻留 = 排空不足风险——两个方向都有代价。**凡本杯动了驻留（延长或缩短），冲完必须在报告里逐段核对流速**：与本类型豆子的历史基线（同档位附近的 runs 流速/每秒流速曲线）对比，**某段流速出现明显异常（骤降、恢复变慢、尾段堵塞形态）= 该驻留决策不合适**，下一杯回退或反向修正。每杯萃取都是一次决策验证：决策 → 观察对应段流速 → 修正下一次方案。
- **尾滴慢 ≠ 缺陷**：细一格就是会拖尾（51 档程序后滴 33 s、口感全对）；只有伴随苦/涩/杂才处理。
- **半步在甜点附近是独立萃取点**：红尾巴 51 实测（50 微苦/52 薄/51 两头全拿）。甜点附近禁 2 格一步。
- **振动**：段前一律 OFF（巴西果效应细粉下沉）；闷蒸后 ON（抹平粉床，安全）；后续段一律 OFF（搅散未贴稳细粉加剧堵孔）。
- **转速**：按 Skill 原规则走——稳定默认 90；清晰/明亮/甜感目标 100–120；厚实感/复杂度 60–80；涩感风险豆 60–90。不作额外人为约束。
- **反馈词汇 → 诊断 → 参数动作**：完整对照表见 `[source-path]/品鉴反馈卡.md` §4（依据 SCA CVA 2024，描述与情感分离）。核心映射：苦=前段过萃→粗 2 格；涩=尾段过萃单宁→粗+末段降温；杂=尾段难溶物→半步粗/限溶剂/末段降温；薄=末段不足或豆性→半步细/段数↑/加粉（凉了更好喝=体质不治）；尖酸=前段不足→半步细；中段空=中段不足→驻留+。
- **限溶剂治尾段杂（待实测）**：水洗高密度豆、症状是"杂"不是"涩"、研磨已对时，可试 1:16→1:15 压溶剂。与老豆 bypass 方向相反勿混用。

## 4. 参数因果链（牵一发而动全身 · 用户 2026-11-06 定框架）

**核心守恒式：水位 = 注水速率 − 排空速率。** 一切水位问题（水叠床、淹床、WAIT）都是这个差值为正；一切"东边不亮西边亮"的参数补偿，本质上都是在调这个等式的两端或换别的方式达到同一萃取目标。

**水位决定萃取模式（用户 2026-11-06 定，浓度梯度物理）**：

- 注水 > 排空 → 水位高 → **浸泡主导**：颗粒泡在同一份渐饱和的水里，浓度梯度随时间衰减 → 萃取效率递减
- 注水 < 排空 → 水位低 → **滴滤主导**：新鲜水持续掠过颗粒，浓度梯度始终拉满 → 萃取效率高
- 推论：水位管理不只是防堵，**是把萃取模式摁在滴滤侧**。段数（分批）、驻留（排空等待）、流速（进水节流）的全部意义在此。
- **"分批给水、快排空把迁移阈值推深"的机制**：细粉堵滤纸 = 细粉被水流动程搬运到滤纸并贴住。段数多 → 单段搬运行程短；快排空 → 粉床内流动总时间短。搬运窗口被压缩 → 更细的研磨才积累出堵的迁移量 → 阈值（临界研磨度）更深。

### 4.5 萃取上限模型（爆炸头/挤巴士 · 用户 2026-11-06 定稿）

1. **可溶物按溶解难度排队上车**：易溶物（花香/酸质/糖）前段就走；难溶物（木质/谷壳/单宁）需要更细的粉或更长接触才"上得了车"。风味强度不足 = 有难溶物留在站台上。
2. **研磨度是难溶物上车的总开关**：越细→表面积越大→更多难溶物变可溶。**细粉是堵的门票**，但堵不堵取决于是否摸到**细粉迁移阈值**（压实+贴壁→流量坍塌）。
3. **阈值是移动的，被其他参数推拉**：水位高/驻留长/振动 → 迁移窗口大 → 阈值变浅；水位低/快排空/分段给水 → 阈值变深。**目标：把研磨推到阈值边上但不越线**，用尾段液重流速形态当探测器（平滑衰减=未越线；平台/骤降=越线）。
4. **莎朵实测（2026-11-06）**：50 档尾段平滑衰减、与红尾巴 51 同量级 → **未摸到迁移阈值，研磨有下调空间**。47 = 朝阈值方向走的第一步，冲后用 §4.4 判读线验证。
5. **均匀萃取是前提，段数链是倒 U 型**（用户 2026-11-07 修正）：磨细只在"每个颗粒喝到相似的水"时才转化为更多风味。段数↑的主效应是**总萃取率↑**（分批新鲜水刷新粉床）；但段数过多→细粉迁移积累→堵滤纸→**旁漏水**（水改走粉间隙未经萃取直接流出）→ EY 反降且严重不均。所以段数是"提 E 的杠杆 + 堵的加速器"一体两面，**适用边界由堵塞判定，不由段数本身判定**；旁漏水的探测器同样是逐段流速形态。
6. **决策含义**：想要"萃取更多"，可动的主变量是研磨、段数、驻留三个，且**研磨和段数互为支撑**（段多→水位低→可更细）；单杯主变量仍只动一个，其余作为联动补偿。

### 4.2 替代关系（东边不亮西边亮）

同一个萃取目标有多条参数路径，**优先动副作用小的，且同杯只动一个主变量**：

- 提萃取率/强度：研磨细 ＜ 驻留长 ＜ 水温高（副作用从小到大：堵风险 vs 细粉迁移 vs 尾段杂）
- 降水位/防淹：驻留长 ＜ 流速慢 ＜ 研磨粗（研磨粗是最后手段，它会丢强度）
- 治尾段杂：末段水温↓ ＞ 研磨粗（先削尾段，再动全杯）

### 4.3 决策流程（每杯定方案必走）

1. 先写主决策（比如"研磨 50→47 求强度"）
2. 查 §4.1 耦合表该行的"必须联检"列，逐项判断是否联动补偿
3. 同杯只允许一个主变量 + 若干被动联动项；把"本杯动了什么、为什么"写进方案说明
4. 冲后报告逐段流速核对（§3 验证条），异常 → 下一杯先回退联动项再谈主变量
5. 口感反馈 + 流速证据一起入账，新结论提炼回本库

### 4.6 双指标账（浓度 TDS × 萃取率 EY · §1 第二层，服务于 §0 总目标）

**每杯方案的每个改动，必须知道它最终影响的是萃取率还是浓度**——说不清动了哪本账的调整不许进方案。两本账的适宜区间见 §1（浓度 1:14–1:18 可接受；EY 18–22%；均匀萃取是前提）。

- **定方案时**：逐项标注动的账——浓度账（TDS，口腔强度：薄/厚/冲击力）还是萃取率账（EY，粉里的东西拿出来多少：空/杂/层次/干净度）。确认两项都朝目标走、互不冲突。
- **收反馈时**：先把用户的词翻译成双指标判断——"薄"是浓度薄（动粉量）还是 EY 低（动研磨/段数/驻留）？"想更强"是提 C 还是提 E？再选参数动作。
- **验证时**：预期效果写成双指标（如"47 = 提 E，预期层次↑、TDS 略↑"），冲后用味觉+流速曲线核对预期是否兑现。
- **方向表**：加粉（保1:16）= C↑↑ / E≈；研磨细 = C↑ / E↑↑；水温↑ = C↑ / E↑；驻留↑ = C↑ / E↑（递减）；段数↑（滴滤侧）= C≈ / E↑更均匀；搅动 = C≈ / E↑；bypass = C↓ / E 不变；限溶剂 1:15 = C≈ / E↓（削尾）。
- **四象限判读**：高C高E=饱满均衡（目标）；高C低E=浓而尖空洞；低C高E=淡而杂（过萃感）；低C低E=水感尖酸。反馈词汇先落象限再动参数。

### 4.7 堵塞链（成因 → 后果 → 探测 → 预防 · 用户 2026-11-07 定：独立成章）

**定义**：滤纸/粉床的渗流通道被细粉占据，排空速率坍塌、水位抬升，部分水改走粉间隙绕过大部分咖啡粉直接流出（**旁漏水**，未经萃取）。

**成因（四层叠加，缺一不堵）**：

1. **物质基础——细粉量**：研磨越细细粉越多；浅烘豆硬且韧→细粉多【实测】；处理法带来密度不均——日晒细粉黏、易迁移压实（更危险），水洗结构紧密细粉略多但迁移可控【实测+推理】
2. **搬运条件——水流动程**：细粉要被水"运"到滤纸才会堵。水位高（注水>排空）、驻留长、搅动（RPM）、振动，都在扩大搬运窗口【推理，莎朵 50 杯水位观察支持】
3. **累积过程——正反馈自加强**：细粉迁移→贴壁压实→渗透率↓→排空更慢→水位更高→搬运更强→更多细粉到位。**堵塞不是线性变糟，是加速变糟**【推理】
4. **触发阈值——临界研磨度**：即 §4.5 的迁移阈值，是移动的，被段数/驻留/水位推拉

**后果（按发展顺序递进）**：

1. **流速坍塌**：尾段液重流速走低、拖尾大幅拉长。注意与正常细研磨拖尾区分——正常拖尾形态仍是**平滑单调衰减**；堵塞形态是**平台/骤降/恢复慢**【实测基线：§4.4 三杯】
2. **旁漏水**：堵死后水改走粉间隙直接流出→**EY 反降**且萃取严重不均——堵区浸泡过萃、旁路区欠萃，杂/涩/空洞并存。味觉 signature：口感前后割裂、浓度骤降、甜感缺失【推理，用户 2026-11-07 点破】
3. **系统风险**：WAIT 报错/机器保护停机

**探测（三信号联读）**：

- 蓝柱逐秒流速形态（主探测器）：平台、骤降、恢复慢 = 堵塞 signature
- 阀侧 vs 液重差值：40523 出水正常但液重增长放缓 = 水积在粉床里没下来
- 味觉：前浓后水割裂、余韵发空

**预防（对冲优先级，从副作用小到大）**：段数分批压缩搬运窗口 ＜ 中段驻留排空 ＜ 主段流速节制 ＜ 振动纪律（段前永远 OFF）＜ RPM 克制（研磨已细时不再加）＜ 研磨不越阈值线。

**修复（已堵之后）**：本杯不可逆转，不推荐加温救（只会让难溶物更多上车）。下一杯：先回驻留（单变量），仍堵 → 研磨回粗 2 格；两杯都堵 → 段数回 4 段基准。

### 4.8 数据接口：液重流速 = 水位与堵塞的唯一观测窗口（用户 2026-11-07 定）

**Agent 没有眼睛，看不到滤杯里的实际水位——液重流速数据就是水位的呈现方式。** 判断"水位高低、偏浸泡还是偏滴滤、有没有堵"全部从逐秒液重流速（报告蓝柱 / run log drain.trace + dispense.pours）读出，三判读：

1. **水位高低判读（注水段内）**：机器按设定速率注水（如 3.5 ml/s），同期杯中液重增速应≈注水速率×0.9634 扣粉床持留。**液重增速明显低于设定 = 水积在粉床里没下来 = 水位偏高**（50 杯观察的注水侧对应物）。配合 40523：阀侧出水正常但液重增长放缓，差值扩大 = 床内积液。
2. **萃取模式判读（浸泡 vs 滴滤）**：看**段与段之间**（驻留期）的液重流速——注水停后液重持续增长且快速衰减到零 = 排空顺畅 = **滴滤侧**；注水停后迟迟不出水、或下一段注水时液重增速进一步变慢 = 排空不足 = **向浸泡侧偏移**（§4 守恒式的数据面）。
3. **堵塞判读（尾段形态）**：见 §4.7——平滑单调衰减=健康；平台/骤降/恢复慢=堵塞 signature；配合尾段总时长 vs §4.4 基线。

**联读规则**：三个判读不是孤立的——"注水段增速低 + 驻留期排空慢 + 尾段形态异常"同时出现 = 堵塞在发展；只出现第一个 = 水位偏高但未堵（用驻留对冲，不动研磨）。每杯冲后按此顺序读报告，结论写进入账 note。

### 4.9 豆侧输入（不可调，但决定每条参数链的"斜率" · 用户 2026-11-07 定）

豆子属性是网络的输入层：Agent 改不了它们，但同一条参数链在不同豆上走出的结果不同——推导时先读豆侧，再定机侧。

**① 烘焙度 AG 链**：AG 数值越大越浅 → 细胞壁结构紧密、风味物质较难萃出 → **需要更细的研磨**。但结构紧密=豆更硬，**同样的研磨设定下硬豆出细粉更多** → 细粉迁移堵的风险同步上升。**推论（硬规则）：AG 很高的豆（极浅）不能一味调低研磨度**——研磨下限被 §4.7 迁移阈值封顶，求强度到阈值边上就停，改用段数/驻留/转速补。

**② 处理法链**：水洗结构紧密 → 密度高、同 AG 更难萃 → 研磨往细走；同时细粉稍多 → 堵风险高于日晒预期。日晒结构相对疏松 → 细粉少但**黏**、易迁移压实堵塞（红尾巴实测：日晒细粉黏）。两条分支殊途同归：**处理法决定"往细走"的步长要小、阈值要盯**，不允许一步跳到底。

**③ 豆龄/排气链（7 天分界，用户 2026-11-07 定）**：豆龄 ≤7 天 = 新鲜 = 排气期内。排出的 CO₂ 阻碍水与咖啡粉的接触萃取。机理：**风味物质萃取集中在前段，排气也集中在前段**——前段慢下来，给气体留出逃逸时间。**硬规则：新鲜豆（≤7 天）全程使用最小档流速 3.0 ml/s**，并**适当延长闷蒸时间（12→15 s）**——两个动作同属一条排气链：慢流速延长全程接触、长闷蒸给前段排气留足时间，共同实现充分排气（用户 2026-11-07 确认：延长闷蒸是帮助豆子充分排气最有效的方法之一）。配套动作：起始档回粗 1 格对冲（既有规则）。超过 7 天排气期基本结束，流速回归默认 3.5。

**三条链的共同落点**：豆侧输入改变的是"同一参数动作的风险收益比"——AG 越高细粉越多（研磨链的代价变大）、水洗更难萃（研磨链的收益变大）、豆越新鲜排气越多（流速/闷蒸链的必要性变大）。推导时逐项过一遍，写进方案说明。
