### 振动机制定性（2026-11-06 新增 · 作为萃取方案制定的影响因素）

**① 段前 / 段后振动的细粉迁移差异**

- **段前振动**（注水前·干粉/刚润湿）：触发**巴西果效应**，震荡使细粉下沉、堵滤纸下渗孔，风险**高**。**水洗高密度豆永远段前振动 OFF。**
- **段后振动——按时机分风险，不是笼统的「低」**：
  - **闷蒸后那一下 = 安全**（细粉刚吸水、尚未开始贴壁堵孔，此时振是「抹平粉床」，没有细粉可搅乱）。
  - **主萃取中后段的每次段后振动 = 风险高**（细粉已被水流陆续推到滤纸、正在贴壁堵孔，此时振会把「尚未贴稳的细粉」重新搅散、迁移到排水口，加剧堵塞）。**一律 OFF。**
- **默认「闷蒸后振动 ON + 后续段 OFF」已是正确位置，不必改。**（此前「段后振动风险低」的表述是把「闷蒸后安全」错误推广到「每一段后都安全」，作废。）
- 依据：细粉吸附在滤纸后被「咬死」无法上移（毛细 + 表面张力 + 纤维锁死三重锁定），而干粉震荡的细粉下沉是巴西果效应——二者方向相反，不可混为一谈。机器振动 ≠ WDT（WDT 是细针局部打散结块，机器是整杯震荡，段前振会帮倒忙）。

**② 湿态振动的物理机制（贴壁细粉振不掉）**

- 真正堵滤纸、决定流速的是**细粉层**，它在湿态下被**三重机制锁死**：水膜表面张力（比颗粒重力大数十倍）、滤纸纤维机械互锁、毛细管负压。机器左右摇摆（水平剪切）的加速度撕不开这层锁定。
- 能被振松回落的是**较粗颗粒**，它堵不住下渗孔，回落反而使粉床更均匀——接近搅拌的正面效果。
- 水平摇摆是**剪切**而非垂直压缩，不会压实粉床（压实需垂直振动触发巴西果效应）。
- **后续段振动该 OFF 的真实原因**：不是「贴壁的粉被振下来」，而是**「尚未贴稳的细粉被反复搅动、重新迁移到排水口」**。
- 旁证：51 档「程序结束后稳定慢滴 33 秒（0.6–0.7 g/s）」= 细粉层把滤纸恒定锁死；若振动真能振掉细粉，尾滴应「忽快忽慢、越来越快」，而非稳定慢滴。

### 转速通过率实验设计（2026-11-06 · 待执行）

> 目标：先回答一个最窄的问题——**xBloom 上 60 RPM 与 120 RPM 磨出的粉，过 20 目筛的通过率到底有没有差异、差多少**。注意：本实验只测「转速→粒径切点」这一环，**不能**直接得出「转速→细粉→风味」的因果链；做完只把「转速是否影响粒径」从「未知」推进到「有数据」。

**实验材料**
- 筛网：20 目（约 850 μm）
- 同一支豆、同一研磨档、同豆量（建议用一支便宜的日晒或水洗豆，别用竞标豆）
- 一台能称到 0.1 g 的秤

**分组与重复（消除批间噪声）**
- 60 RPM 磨 3 次，120 RPM 磨 3 次，**交替顺序**（60/120/60/120/60/120），避免刀盘升温随固定顺序累积
- 每次磨完立即过筛、称重、记录，**不要**6 次磨完再一起筛

**单次流程（每次都一样）**
1. 秤豆（固定克数，比如 20 g）
2. 磨豆（记录实际转速）

**怎么判结果**
- 算 60 组的通过率均值、120 组的通过率均值，看两者差多少
- 若差值 < 约 1%（相对你秤的精度）→ 转速在 xBloom 上粒径影响可忽略，转速变量可以彻底放下
- 若差值明显（> 2–3%）且三组重复稳定 → 转速确有粒径影响，再考虑下一步（加更细档筛网、或直接上「同豆不同转速」冲煮对照）
- 若三组重复之间抖动很大 → 说明批间噪声盖过了转速差异，单筛网+三次重复不够，需要更多重复或更严控温度

**关键提醒**
- 刀盘温度是隐藏变量：连续磨豆刀盘升温，可能比转速更影响粒径。交替顺序只是缓解，不能消除；如果条件允许，每两次磨豆之间等刀盘回到室温。
- 20 目只切一个粒径点，看不到「双峰/单峰」的分布形状；本实验是「有没有差异」的粗筛，不是「细粉怎么分布」的定论。
