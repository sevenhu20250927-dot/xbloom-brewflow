# 发布者的冲煮偏好

这是本项目发布者的档案，供解释其历史配方与复用其个人习惯。首次安装的其他使用者不自动继承；若选择这套习惯作为起点，应在个人`preferences.md`明确记下选择及本地标定。

| 条件或偏好 | 依据与适用范围 |
| --- | --- |
| 办公室机磨固定60 RPM | 噪声约束；用户喜欢低速。不证明低速的颗粒均匀度一定更好。历史100／110 RPM照原值保留 |
| 通常15g | 一般约束；用户指定16g时按当次决定，不回写全部历史 |
| 日常1:15，特别好且用户指定的豆可考虑1:16 | 比例可调整，不是硬锁；不能仅凭豆名、金标或价格自行认定 |
| C40普通轴22–25约对应xBloom48–55 | 用户提供的体感标尺。22偏细、25偏粗，日常23–24；仅在此区间近似插值，不是粒径或筛网等价 |
| C40约23格可参考xBloom50；22格参考48 | 区间线性近似，`C40=22+(xBloom−48)×3/7`；不要求C40拧到小数格，也不外推为浓缩刻度 |
| 出方优先一一框架；近邻优先处理法 | 同豆同批实际反馈优先，缺完整配方时比较2–3例并说明取舍。延长发酵水洗不自动归为日晒 |

出处：[历史配方规则](历史配方规则.md)、[本地工作区补充](本地工作区规则.md)。后者的处理法规则由Karamo实喝触发，具体条件与待试方案见[Karamo记录](../log/库存63-Karamo延长发酵水洗/20261112-首次拟方/记录.md)。

此前记录提出的筛网通过率、价格分档和温度偏好均是当时条件下的观察或选择；不能把别人的研磨器、滤杯、批次与用户自己的标尺自动等同。用户对旁通成功的观察证明了当次动作发生，不证明旁通水温已实测或其风味影响已独立验证。
